# 头像裁剪配置
# Portrait Crop Configuration
# ============================

## 裁剪规则 (Crop Rules)

### 目标区域
- 位置: 肩部以上
- 比例: 1:1 正方形
- 主体: 头部和肩膀

### 裁剪参数
- crop_region: "shoulder_up"
- aspect_ratio: "1:1"
- padding_top: 10%    # 头顶留白
- padding_sides: 5%   # 两侧留白

## 处理流程 (Processing Steps)

1. 检测人脸/头部位置
2. 计算肩部位置（通常在头部下方 1/3 处）
3. 确定裁剪框
4. 按 1:1 比例裁剪
5. 输出结果

## 输入输出 (Input/Output)

### 输入
- 源图像: 立绘或表情图（膝盖以上）
- 格式: PNG/JPG
- 建议最小尺寸: 512x768 (2:3 比例立绘)

### 输出
- 裁剪后头像: 1:1 正方形
- 格式: PNG（保持透明度）
- 建议输出尺寸: 256x256 或 512x512

## 裁剪示意图 (Crop Diagram)

原始立绘 (2:3):
```
┌──────────────┐
│   ┌──────┐   │  ← 裁剪区域 (1:1)
│   │ HEAD │   │
│   │SHOULDER  │
│   └──────┘   │
│    BODY      │
│              │
│    KNEE      │
└──────────────┘
```

输出头像 (1:1):
```
┌──────────────┐
│              │
│     HEAD     │
│   SHOULDER   │
│              │
└──────────────┘
```

## 批量处理 (Batch Processing)

当处理 2x2 表情图时:
1. 首先将 2x2 图片分割为 4 张独立图片
2. 对每张图片执行头像裁剪
3. 输出 4 张独立的 1:1 头像

## 工具建议 (Recommended Tools)

- Python: PIL/Pillow, OpenCV
- 人脸检测: dlib, mediapipe
- 云服务: AWS Rekognition, Google Vision API
